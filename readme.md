# SyncLife

A personal life-tracking app — meals, workouts, water, finance, and gold — synced to Google Sheets.

## AI Coach Calls

SyncLife can "call" you like an alarm to motivate you into the gym or into focused work:

- Set daily call alarms in **Profile → AI Coach calls** (gym or work, any time). The app asks for notification permission when you enable one.
- At the scheduled time a full-screen **incoming call from SyncLife Coach** notification fires. Tap to answer.
- On answer, the coach **speaks a motivational message out loud** (text-to-speech), personalized with your name, streak, and whether you've worked out today.
- Messages are generated by Claude via the backend (`POST /api/motivation`, requires `ANTHROPIC_API_KEY` in `backend/.env`). Without a key — or offline — the app falls back to a built-in motivational message bank, so the call always connects.

## Project Structure

```
SyncLife/
├── frontend/     ← Expo / React Native app (Play Store)
└── backend/      ← Node.js / Express API server (deployed separately)
```

## Frontend (Expo)

```bash
cd frontend
npm install
npm start                # Expo dev server
npm run android          # Run on Android device/emulator
```

Set `EXPO_PUBLIC_API_BASE_URL` in `frontend/.env` to point to your backend.

## Backend (Node.js / Express)

```bash
cd backend
npm install
npm run dev              # Development with hot reload (port 3001)
npm run build            # Compile TypeScript
npm start                # Run production build
```

See [backend/README.md](backend/README.md) for full API documentation.

## Deployment

| Project | Where | Command |
|---------|-------|---------|
| Backend | Render / Railway / Fly.io | `npm run build && npm start` |
| Frontend | EAS Build → Play Store | `eas build -p android --profile production` |

Set `EXPO_PUBLIC_API_BASE_URL=https://your-backend-domain.com` before building the app.
